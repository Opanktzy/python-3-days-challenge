## 🎯 Overview

**Python Data Management System** adalah aplikasi command-line yang powerful untuk mengelola data mahasiswa dengan fitur analisis data lengkap. Dibangun dengan Python murni dan library data science terbaik.

### 🎯 Key Highlights
- 📊 **Real-time Analytics** dengan NumPy & Pandas
- 📈 **Interactive Visualizations** dengan Matplotlib
- 🌐 **API Integration** untuk data eksternal
- 💾 **Multiple Export Formats** (JSON, CSV)
- 🔍 **Advanced Search & Filtering**
- 🎨 **Beautiful CLI Interface**

## 📦 Installation

### 📋 Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### 🔧 Step-by-Step Installation

#### 1️⃣ Clone Repository
```bash
git clone https://github.com/yourusername/python-data-manager.git
cd python-data-manager

# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt

🚀 Quick Install (One Command)
git clone https://github.com/yourusername/python-data-manager.git && cd python-data-manager && python -m venv venv && source venv/bin/activate && pip install -r requirements.txt
